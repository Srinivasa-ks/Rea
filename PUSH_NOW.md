## 🚨 Important Notes

### GitHub Pages Configuration

After pushing, you **MUST** enable GitHub Pages:

1. Go to repository settings
2. Navigate to Pages section
3. **Select "GitHub Actions" as source** (not "Deploy from a branch")
4. Save changes

If you select "Deploy from a branch", the site won't work correctly!

### First Deployment

- First push may take 2-3 minutes
- Subsequent pushes are faster (1-2 minutes)
- GitHub Actions builds automatically on every push to main

### Testing Your Site

After deployment:
1. Visit: https://srinivasa-ks.github.io/Rea-Agenti-AI/
2. Test all 7 screens
3. Try the sandbox environment
4. Toggle dark/light theme

## 🐛 If Something Goes Wrong

### Push Fails
```bash
git pull origin main
git push origin main
```

### 404 Error After Deployment
- Wait 2-3 minutes
- Hard refresh browser (Ctrl+Shift+R)
- Verify "GitHub Actions" is selected as source

### Assets Not Loading
- Check vite.config.js has correct base path
- Rebuild: `npm run build`
- Push again
