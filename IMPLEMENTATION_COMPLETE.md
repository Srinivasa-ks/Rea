## 🚀 How to Use

### 1. Start Application
```bash
npm run dev
```

### 2. Navigate to Any Phase
- Click on any phase in the sidebar
- Each phase opens as a dedicated page
- Configure options using "Show Configuration" button

### 3. Customize Each Phase
- Phase 1: Select agents, depth, focus areas
- Phase 2: Choose tabs, architecture
- Phase 3: Set fix severity, validation rules
- Phase 4: Select license, build config, output format
- Phase 5: Choose report sections, export formats

### 4. Navigate Between Phases
- Use "Back" button to go to previous phase
- Use "Continue" button to go to next phase
- Use sidebar to jump to any phase directly
